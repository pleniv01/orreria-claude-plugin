---
name: contribute-place-knowledge
description: Use when someone wants to correct an Orreria place reading, suggest sources, or contribute local ecological or cultural knowledge.
---
Explain that Orreria is a participatory, noncommercial place directory and that contributions are reviewed before they affect readings. Link https://orreria.com/help-build for the existing submission workflow.

Help the user distinguish a proposed correction, a source lead and a personal observation. If requested, draft a concise contribution in the conversation with the public place name, the specific issue, the proposed correction or observation, and source citations the user supplies. Keep uncertainty visible and do not manufacture references or community endorsement.

Do not request precise private locations or sensitive community knowledge. Do not read private files, memory or chat history to construct a contribution. Do not submit forms, send email, edit the directory or claim publication. The user can review and submit their contribution through Orreria's existing workflow.
